# Revenant — Forgeware 0.01

Forgeware 0.01 is the first lightweight UI prototype for Revenant, a black-and-red social platform concept.

## Open the prototype

Open `index.html` in a modern browser, or publish this folder as a static website. The interface is a single HTML file with no external JavaScript libraries, build step, or local server required.

## Included in this version

- Revenant black-and-red theme and responsive desktop/mobile navigation
- Home, Feed, Posts, Reels, Messages, Communities, Profile, Settings, and Terms & Rules destinations
- Advanced command bar: `/home`, `/feed`, `/posts`, `/reels`, `/terms`, `/settings`, `/messages`, `/communities`, `/profile`, and `/help`
- First-visit age declaration, the “Burch” terms joke, and a short community-rules gate
- Local demo profile setup, seeded posts, creating posts, likes, replies, bookmarks, and exportable demo data
- Built-in comment fonts, session-only direct font-file loading (TTF/OTF/WOFF/WOFF2), and small image/GIF attachments
- Responsive layouts and keyboard navigation shortcuts (Ctrl/Cmd+K and /)

## Important prototype limitations

This is a **front-end prototype**, not a production social network. Profiles, posts, likes, and replies are stored locally in the current browser and are not shared with other users. There is no real authentication, shared database, backend, livestreaming, video hosting, remote GIF search, ZIP font extraction, or server-side font conversion yet. Demo credentials do not protect a real account.

The birthday screen is a self-declared age gate, not verified age assurance. The short rules shown in the prototype are not a complete Terms of Service or Privacy Policy. Before a public launch, add a secure backend, account recovery, content/media storage, moderation and appeals, privacy controls, appropriate age-safety measures, and complete legal documents.
